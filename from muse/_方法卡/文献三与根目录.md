### 1. ARR_Project_10_Stage1_report_Final.pdf
- 题名 / 作者 / 年份 / 期刊（含卷期页或 DOI）：Australian Rainfall and Runoff Revision Project 10: Appropriate Safety Criteria for People — Stage 1 Report, P10/S1/006 / Cox R.J., Shand T.D., Blacka M.J.（Water Research Laboratory, UNSW）/ 2010-04 / 工程指南报告（Engineers Australia），无 DOI，ISBN 978-085825-9454
- 研究问题：把 1973–2008 年六组人体失稳实验合并重分析，给出「什么水深×流速组合对行人仍算安全」的分级判据；并说明旧版 ARR 的单一 D·V=0.4 为什么不够。
- 方法（关键设计，不超过 5 行）：
  1. 分析单元是「单个受试者的一次暴露试验」；被解释量统一为 D·V（水深×流速，m²/s），解释量为身高×体重 H·M（m·kg）。
  2. 六组实验（Foster & Cox 1973；Abt 1989；Takahashi 1992；Karvonen/RESCDAM 2000；Yee 2003；Jonkman & Penning-Rowsell 2008）逐组复核试验台、地面材质、衣着鞋、失败定义（Table 1）。
  3. 合并回归 D·V = f(H·M)，比较含/不含 Abt 数据的拟合（Fig. 3，r² 0.50 / 0.80），并用 t 检验判 Abt 数据是否来自不同总体（§2.1.7）。
  4. 不按 H·M 连续取值定标准，改为三档人群（H·M≤25 / 25–50 / >50）给 D·V 分级表（Table 5），再叠加「最大水深」「最大流速」两个硬上限（Fig. 8）。
  5. 另收录两套替代判据作对照：Ishigaki 的单位宽度力 M0=V²/(2g)+D²/2 四档（Table 4）；Ramsbottom 的 D(V+0.5)+DF 分级（Table 3）。
- 数据（样本量、地区、时间、来源；只作参考）：六组实验室/渠道试验，受试者合计约 41 人（儿童 6+4、成人 20+3+7+1），水深 0.09–1.2 m、流速 0.58–3.12 m/s、D·V 0.16–2.13（Table 1）；澳大利亚+日本+芬兰+英国，1973–2008；无新实验。
- 可学的方法（具体到能落到哪一层、怎么操作）：
  1. **用「人群档」代替个体生物量**：文中的关键让步是承认 H·M 连续取值在人口尺度上不可操作（§3），于是切成三档。我们没有每个 agent 的身高体重时，这一步是唯一可行路径。
  2. **三件套判据**：乘积阈值 + 深度上限 + 流速上限同时生效，缺一就会把「深而缓」或「浅而急」误判为安全（Fig. 8 与 §4 的说明）。
  3. **失败模式由水深决定**：浅水高流速→滑动（摩擦）失稳，深水→倾覆（力矩）失稳，更深→浮起（§1、§2.2.2 引 Keller & Mitsch；§4 首段）。这给出「水深不仅改概率，还改机制」的结构。
  4. **失稳不可逆**：一旦失去立足，坐/卧姿态迎流面积更大，几乎不可能恢复（§3 末、§2.1.1 引 Foster & Cox 的「坐姿最不稳」）——可直接写成 agent 状态的吸收态。
  5. **给判据标适用域**：明确写出「>1.2 m（成人）/>0.5 m（儿童）、>3 m/s 无数据」，并单列「幼儿与体弱者任何水流都不安全」（Executive Summary、Table 5 脚注）。
- **只用方法、不用他的数，我们该怎么做**：①给每个 agent 只存身高与年龄段，映射到三档（幼儿/儿童/成人），不追求 H·M 连续值；②判定「能否通过某栅格」用三条件：D·V ≤ 阈值(k)、D ≤ 深度上限(k)、V ≤ 流速上限，k 为人群档；③三个参数不取原文值，用 DC 场景自己标定：先固定深度/流速上限（由人体高度比例给，如 0.6×身高、1.2×身高），再对 D·V 阈值做 0.2–1.0 的敏感性扫描，报告结论翻转点；④把「失去立足」写成不可逆状态：进入后只能漂移/等待救援，不能自行恢复行走；⑤按水深切换失稳机制标签（滑动/倾覆/浮起），供伤亡层分别记因；⑥在模型说明里照抄一份「适用上限与不适用人群」清单。
- 不可搬的数（列出具体数值并说明为什么不能进我们的模型）：D·V=0.4 / 0.6 / 0.8 / 1.2 m²/s；儿童水深上限 0.5 m、成人 1.2 m；流速上限 3.0 m/s；H·M 分界 25 与 50；Ishigaki M0=0.1/0.125/0.2/0.25；回归式 D·V=e^(0.022(H·M/25.4)+1.09)−0.0929（§2.1.2）。原因：全部来自 1–20 人的实验室静水/渠流暴露，受训程度、鞋底、地面材质（混凝土/草地/藻面）与「感到不安全 vs 真的跌倒」的定义差异支配；作者自己指出同一受试者重复测试可提高耐受值（Executive Summary、§2.1.7），因此这些数不是给定水情下的人群失稳概率。
- 落点：伤亡层（阈值结构）、水动力（读深/流速的口径）、验证口径（适用域声明）。

### 2. IJDRR_119-105315.pdf
- 题名 / 作者 / 年份 / 期刊（含卷期页或 DOI）：Staying or leaving: Unraveling the dynamics of evacuation decisions among floodplain residents in central Vietnam / Vo Hoang Ha, Nguyen Cong Dinh, Takeshi Mizunoya / 2025 / International Journal of Disaster Risk Reduction 119: 105315，DOI 10.1016/j.ijdrr.2025.105315
- 研究问题：2020 年越南中部洪水里，为什么有些农户「低水位时就完整撤离」，有些等到水涨才走或干脆不走；七组因素（人口学、危险性、经验、威胁评估、应对评估、对外部救援信任、撤离障碍）各自的作用方向。
- 方法（关键设计，不超过 5 行）：
  1. 分析单元是「农户」，因变量二值化：低水位时全家完整撤离且不依赖大量外部援助 =1，其余（不走/部分走/等水涨/靠救援）=0（§3.2.2）。
  2. 模型为二元 logistic 回归，15 个自变量按七组概念块组织（Table 3、Fig. 1），系数以 Exp(B) 报（Table 5）。
  3. 拟合检验：Hosmer–Lemeshow（χ²、df、p）、Nagelkerke R²、分类正确率表（Table 4）；另给 Pearson 相关矩阵查共线（Appendix Table 1）。
  4. 质性与量化并行：6 场小组讨论（每场 11–16 人）+ 7 个关键知情人访谈，用来解释系数方向（§3.2.1、§4）。
  5. 抽样用 Taro Yamane 公式定最小样本，按「受淹≥0.5 m 的农户」名单随机抽（§3.2.1）。
- 数据（样本量、地区、时间、来源；只作参考）：407 户有效（目标 445），Thua Thien Hue 省 Phong Dien/Quang Dien/Huong Tra 三县，2023-01–04 面访（试点 2022-07）；户主 80.6% 男性、96% 初中及以下、70.3% 农业；室内水深均值约 1.29 m。
- 可学的方法（具体到能落到哪一层、怎么操作）：
  1. **把「撤离」定义成带时序与完整性的四态判据**，而不是「是否离开」。这个定义直接决定我们仿真里「成功撤离」的计数口径。
  2. **逐因素块检验而非一次全塞**：先看人口学块是否显著，再看心理/信任块。我们做参数敏感性时也应分块报告，避免「全模型都不显著」掩盖真实驱动。
  3. **「信任外部救援 → 不撤离」的替代效应**：作者把负系数解释为「把等待救援当作撤离的替代品」（§4.2.2.6）。这要求模型里必须有「原地等待救援」这个动作，否则会系统性高估撤离率。
  4. **用 OR 的符号定依赖方向、不用量级定概率**：这类截面调查的系数受样本截断与本地制度支配，只可作定性约束。
- **只用方法、不用他的数，我们该怎么做**：①决策层给 agent 四态：早撤离（水深 < 个人阈值）/ 迟撤离（水深已高）/ 原地不动 / 等待救援；②按七块建 agent 属性表，其中人口学与住房/车辆用 DC 本地数据（ACS/PUMS、NHTS）填，威胁评估/应对评估/信任/障碍四块给显式参数并标为假设；③把「对外部救援的信任」只接到「等待救援」动作的权重上，不直接压低撤离概率；④先跑两个极端（只由威胁评估驱动 / 只由应对评估驱动），看伤亡排序是否翻转，翻转即说明参数不可辨识；⑤报告分块结果，不报单一总模型。
- 不可搬的数（列出具体数值并说明为什么不能进我们的模型）：407 户；分类正确率 82.1%（86.0%/76.6%）；Nagelkerke R²=0.60；OR=3.13（洪水不可预测）、0.70（信任房屋坚固）、0.45（自信已备）、0.43（信任地方政府）、0.60（信任邻居）、0.68（担心财产损失）；各 p 值。原因：越南中部农村、2020 年、户主以男性农民为主、住房以半永久为主、村委/宗族互助为核心制度；样本还被「≥0.5 m 受淹」截断，方差被压缩，OR 不可外推为 DC 的行为概率。
- 落点：决策层（四态与替代动作）、数据来源（本地化替换）。

### 3. J Flood Risk Management - 2026 - Xu - Micro‐Behavioral Responses for Enhancing Urban Flood Resilience  Stated Preference.pdf
- 题名 / 作者 / 年份 / 期刊（含卷期页或 DOI）：Micro-Behavioral Responses for Enhancing Urban Flood Resilience: Stated Preference Analysis of Residents' Evacuation Choices in High-Density Urban Areas / Jia Xu, Yongzhen Wang, Can Wang, Qiang Lin / 2026 / Journal of Flood Risk Management 19: e70272，DOI 10.1111/jfr3.70272
- 研究问题：在内涝情景下，居民选撤离路线时在「距离 / 瓶颈类型 / 交通控制 / 组织方式」四者间如何权衡；这种权衡在性别、年龄、学历、居住年限上是否分组不同。
- 方法（关键设计，不超过 5 行）：
  1. 分析单元是「一次选择任务」：8 个任务 × 2 条备选路线 + 「都不选」，分数折因设计保证水平平衡（Table 1、Table 2，§3.1）。
  2. 模型为条件 logit（McFadden），属性系数跨备选一致；个体固定效应由条件似然消掉（§3.3）。
  3. 异质性用交互项分组估计，逐组报系数与显著性（Table 4），不切分样本。
  4. 情景评估：用估计系数给三条真实路线算效用，再做「封下穿/升级信号」干预前后对比（§4.3、Fig. 2）。
  5. 拟合只报 LR 检验与 pseudo R²，作者明说以「方向与相对重要性」为目标而非预测精度（§4.1）。
- 数据（样本量、地区、时间、来源；只作参考）：335 份回收、307 份有效（91.64%），每人 8 个任务；「都不选」无人选择故剔除，得 4912 条有效观测；北京通惠河走廊（朝阳区），2025-06–09，线上+线下；样本 58.3% 为 18–30 岁、63.19% 本科/大专。
- 可学的方法（具体到能落到哪一层、怎么操作）：
  1. **把「路线安全」操作化为「瓶颈类型」枚举**（下穿通道 / 跨河桥 / 主干道），这是可落到路网图层上的离散标签，不需要连续风险场。
  2. **等效距离折算**：用 β_属性 / β_距离 把非距离属性换成「多少 km 距离惩罚」（§4.3 的算法，不含其数值）。这是把定性风险接入路径效用的最干净方式，也让结果可向规划者解释。
  3. **分组异质性用交互项**：样本不大时也能给出「哪一类人更避下穿」的方向性结论。
  4. **情景对比用配对**：同一批路线、同一组系数，只改一个属性，报效用差而不是绝对效用。
  5. **诚实交代弱解释力**：pseudo R² 极低仍下结论，但限定在「方向」。我们复用其结构时必须重复这个限定。
- **只用方法、不用他的数，我们该怎么做**：①在路网层给每条候选路径打三个标签：瓶颈类型（下穿/跨河桥/地面干道）、引导方式（官方路线+信号 / 自导航）、距离；②先在 DC 路网里列出全部下穿与跨河桥，作为「风险节点」清单（这是本文最可直接搬的产物）；③效用写成 U=β_d·d+Σβ_b·bottleneck+β_g·guidance，β 先只定符号与序（下穿最负、桥次之、引导为正）；④把 β_b/β_d 解释为「绕多少 km 才愿避开一个下穿」，这个比值由我们在 DC 做小样本问卷或直接扫参得到，不用北京值；⑤干预情景只报「同一 agent 群体在干预前后的效用差与改路比例」。
- 不可搬的数（列出具体数值并说明为什么不能进我们的模型）：−1.482（下穿）、−0.762（跨河桥）、+0.055（距离）、+0.632（智能信号+官方路线）、−0.471（无信号+自导航）；4912 观测；pseudo R²=0.0052；「1.48/0.055≈27 km」「0.63/0.055≈11.5 km」；307 份样本构成。原因：北京通惠河走廊、2025 年、且情景假设「政府已下强制撤离令 + 房屋可能倒塌」（§3.1），此时人才几乎不选「都不选」；距离系数为正本身是设计与属性共线的产物（作者自承 §4.1），不是「人喜欢远路」。pseudo R² 0.005 说明模型解释力极弱，绝对值不可移植。
- 落点：决策层（路径效用）、验证口径（配对情景）、数据来源（瓶颈节点清单）。

### 4. NCHRP-562-Improving-Pedestrian-Safety-at-Unsignalized-Crossings.pdf
- 题名 / 作者 / 年份 / 期刊（含卷期页或 DOI）：Improving Pedestrian Safety at Unsignalized Crossings（TCRP Report 112 / NCHRP Report 562）/ Fitzpatrick K., Turner S., Brewer M. 等（Texas Transportation Institute）/ 2006 / Transportation Research Board，ISBN 0-309-09859-9，Project D-8/3-71
- 研究问题：无信号人行横道处，哪类工程措施（红线信号/感应警示/高可视标志/中央避险岛）能提高机动车让行率；行人过街的速度、间隙接受、延误、冲突如何随年龄与道路条件变化。
- 方法（关键设计，不超过 5 行）：
  1. 分析单元是「一次过街事件」（群体/簇只记领头者，整群计一次），42 个站点、7 个州（§7 开头、Table 16）。
  2. 观测协议固定为 7 类 MOE：视觉搜索、横道内合规、设施激活、人车冲突、延误、步行速度、机动车让行（Table 15），视频+掌上电脑双记录（§6 数据收集）。
  3. 另设「摆拍行人」测让行：统一着装、站位于路缘 0.3 m 内、每站≥40 次、超 1 分钟放弃（§6 staged pedestrian tests），以消除行人姿态差异。
  4. 步行速度按年龄/性别分组，用 F 检验比较第 15 与第 50 百分位（§7 步行速度、Table 18–19）。
  5. 间隙接受按「每个进口道单独」做 logit 变换，取 85% 分位接受间隙，共 47 个独立分析（§7 间隙接受、Table 23）。
- 数据（样本量、地区、时间、来源；只作参考）：42 个地点（40 个自采 + 2 个由他方提供视频；其中 40 个在美国西部，§6 Site Selection），3,155 次过街（81% 步行）；采集年份为 2003 年（§8 步行速度讨论明写 "data collected in 2003 for the TCRP/NCHRP study"）；来源为现场视频 + 掌上电脑记录 + 站点几何测量。
- 可学的方法（具体到能落到哪一层、怎么操作）：
  1. **MOE 清单即「行为可观测项」字典**：把「看没看两边 / 是否在横道内 / 是否按按钮 / 是否冲突 / 等了多久」写成 agent 状态与日志字段，比只记「是否通过」信息量大得多。
  2. **用第 15 百分位而非均值定慢速人群参数**：这是交通工程的标准做法（保守侧），可直接用于我们给老人/儿童设速度。
  3. **「rolling gap」概念**：行人不等到整条路全空，而是逐车道找可接受间隙；映射到内涝就是「逐段找干区/浅水带」，路径决策应是分段马尔可夫式而非一次性全程判定。
  4. **分方向、分进口道独立分析**：同一地点的两个方向机会结构不同，不能合并。我们的路口/下穿也应分方向建模。

- **只用方法、不用他的数，我们该怎么做**：①把问卷条目转成 agent 字段：warning_source（0–4）、warning_content_level（0/1/2/4）、prior_flood_count、surprise、knowledge_level；②用「来源可信度」而非「是否收到」决定起步延迟的乘子；③「内容等级」接到动员概率上（等级越高，延迟越短）；④水深沿用 7 档边界作为**显示档**，不作物理阈值；⑤有序 logit 只取符号与序，系数不取。
- 不可搬的数（列出具体数值并说明为什么不能进我们的模型）：n=1315；42.7% 官方警告 / 34.8% 无警告；46.8% 污水系统、43.0% 坡面流、76.3% 河流溢流、9.2% 溃坝、28.8% 地下水；系数 0.493（性别）、0.571（官方警告）、0.147（内容质量）、0.680/0.901/2.010（既往 1/2/3 次）；惊讶度均值 5.56。原因：德国 2021 年 7 月、砖石住宅带地下室、官方警告覆盖率低这一特定失败模式；DC 的预警渠道（WEA/短信/社媒）与建筑形态不同，各比例与系数不可移植。
- 落点：数据来源（问卷工具与编码表）、时间层（响应延迟）、决策层（信息质量）。

## 最该学的 3 个方法

1. **两级计时 + 三档区间**（Silva 补充材料 S1/S2 + Thieken 补充材料 Table S1）：把「收到警告」与「开始行动」拆成两条独立曲线，每条给上/中/下三档，输出区间而非点估计——解决我们时间层最大的一个混淆（预警覆盖 vs 人的犹豫）。
2. **把非距离风险折算成等效距离/等效分钟**（Xu §4.3 的比值法 + Ahsanuzzaman 的 WTP=δ/γ）：让「下穿风险」「提示方式」「绕行时间」进入同一个可加效用，且结果能向规划者解释（「绕一个下穿值得多走几公里」）。
3. **验证拆成趋势 + 数量 + 尺度三层**（Tang 补充材料 Method 3、Table S3）：二值混淆矩阵看热点是否漏掉、MAE/秩相关看强度、2–3 个分辨率重复看稳健性，再用 TOST 说「等价」而不是「不显著」。

## 最该警惕的 2 个坑

1. **把实验室阈值当物理常数直接搬**：ARR 的 D·V=0.4/0.6/0.8/1.2、WRL 的 D·V≤0.3/0.6 与 C_D=1.2–2.0、Li 的 0/0.35/0.60/0.90 m 与容量降幅——它们分别绑定了受试者样本（1–20 人）、地面摩擦与稳态流、两辆具体车、健康大学生与静水泳池。搬数会让模型在 DC 的「深而缓」「浅而急」「老幼人群」三类情形上系统性出错。只能用其**结构**（三件套判据、力平衡、速度折减函数），阈值必须重标定并声明适用上限。
2. **把 SP/WTP 系数或 logit 的 OR 当行为概率**：Xu 的 pseudo R² 只有 0.005、Borowski 与 Ahsanuzzaman 的金额/分钟是该样本在该情境下的边际替代率、IJDRR 的 OR 受「≥0.5 m 受淹户」截断与本地宗族制度支配。跨城市、跨制度、跨灾种直接套用会把「北京人避下穿」「越南农户信村委」当成 DC 人的行为参数。只取符号与相对序，量级一律在 DC 重新标定，并做 ± 敏感性说明结论是否翻转。
