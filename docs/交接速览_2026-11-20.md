## 四、怎么跑

```bash
# 单工况（自带临时静态服务，跑完自动关）
cd web && node sim/sim-sweep.mjs u_p32_s0 1 1000 1440 out/sweep_v3
# 八工况（并发 2，内存 15.4 GB 机器上别开 3）
cd web && node sim/sim-sweep.mjs all 2 1000 1440 out/sweep_v3
# 数据表
py tools/report_person_hours.py web/out/sweep_v2
```

- `sim-sweep.mjs` 参数顺序：`工况(或 all、或逗号分隔) 并发 人数 分钟 输出目录`。
- `sim-day.mjs` 环境变量：`SIM_BATCH` / `SIM_BATCH_TIMEOUT`（默认 180 s）/ `SIM_SLOW_MS` / `SIM_VIEW` / `SIM_FOUND`。
- 内存实测：一个无头 Chrome 常驻约 1.8–2.0 GB，**强制 GC 后存活堆恒定 525 MB**（无泄漏）。
- 改文件用原生 `edit`/`write`：`ops_edit_file` / `ops_read_files` 在本机会报 `PUBLICATION_GRANT_UNAVAILABLE`。
- `git` 只在 MSYS bash 里可用（PowerShell 里没有）。
