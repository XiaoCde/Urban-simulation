## 二、决策门序列（五道门，串行，任一挡死则 p=0）

```
门1 接收      收到预警？      receiveAt = 发布 + 扩散延迟（Silva A1.2 实测锚点）
门2 风险识别  危险度分级      HR = d(v+0.5)+DF（FD2321）→ low/some/most/all → 威胁档
门3 启动      动员率 M(t)     Silva S2 实测点插值 × 经验倍数 exp(κ·Δknowledge)
门4 选择      P = σ(U撤离−U留下)   Borowski & Stathopoulos 2023 Table 4 原样（百美元单位）
门5 阻碍      改可行集而非清零  no_vehicle → 步行；on_duty 且危险度 most/all → 解除值守
```

- 从众：**阈值级联**（`P(跟随|已撤 x) = 0.720·I_x(1.13,1.60)`，Rufat 2024 Fig.2 五点拟合），与 Borowski 的 7.76 加性系数**互斥**（同一渠道，不许同时开）。
- 经验：只走门 3 的 AFT 形式 `M(t·ratio)`（Hasan 2013 TR-C 27:108–116），`κ=1` 是唯一自由标量。
- 决策锁定：情境签名不变 30 分钟内复用；雨强跨档（0/<5/<15/<30/≥30 mm/h）立即重估。

## 三、伤亡判据

| 判据 | 公式 / 阈值 | 依据类型 |
| --- | --- | --- |
| 静水溺亡深度 | 气道高 = 0.85 × 身高；身高按 NHANES 2016 分年龄分性别表 | 文献（身高）+ 半自设（0.85 系数，敏感性 0.85–0.90） |
| 耐受时间 | `endurance = 暴露基线 × (wadingSpeed(d)/1.67)` | 推导（Li 2026 步速比）；基线 150/80 s 自设 |
| 被困 | 原地不动时间 > `0.5 × endurance` | 推导（排序约束：被困必须早于死亡） |
| 涉水受伤 | `D·V` 线性映射：成人 0.6→1.2 m²/s、儿童 0.4→1.2 | 文献（ARR Project 10 / Keller & Mitsch 1993） |
| 被冲走 | `?swept=unstable` 时：`D·V ≥ 1.2`（成人）/ `0.55`（<13 岁）→ 判死 | 文献阈值 + 自设「达阈值即判死」（上界口径，默认关） |
| 车内 | 0.15 m 熄火被推移 / 0.60 m 漂浮；漂浮中滞留 > 0.8×endurance → 溺亡 | 文献（Smith 2017）+ 推导 |
| 室内 | 楼层淹没：行动不便 1.52 m、能行动 天花板−0.30 m；顶层被淹走 Jonkman 2007 | 文献（LifeSim CPD-97a / Jonkman） |
| 地下室 | 下到地下室概率 0.35（情景参数）；水深 = 地面 + 2.2 m（IBC 净高推导） | 半自设，须报 0.20/0.50 敏感性 |

## 四、水动力与排水

| 项 | 值 | 依据 |
| --- | --- | --- |
| 二维浅水 | 8 m 网格，45 分钟一帧，32 帧/工况 | 模型设置（算力约束，非文献） |
| 雨水口入口能力 | 37.6 mm/h（每街面格） | NOAA Atlas 14 DC 60-min 2-yr = 1.48 in/h |
| 排水通过能力 | `Q = C × i × A` = 0.714 × 37.6 mm/h × 30.6 km² = **228 m³/s** | 公式文献惯例；A 用模型域（30.6 km²）；C 从 landcover 分类面积加权得 0.714 |
| C 敏感性 | 0.60 / 0.714 / 0.80 → 192 / 228 / 255 m³/s | 需重导帧才生效 |
| 满管调蓄桶 | 23.9 mm 后降到 5%，6 h 放空 | 193 Mgal ÷ 30.6 km² = 23.9 mm（DC Water LTCP） |
| 服务率 | `served_now = min(1, Q/需求) × 桶因子` | 逐步重算（旧版整段常量是 bug） |
| 街道 | 街面栅格下压 0.11 m；**没有一维街网耦合** | `street_net.py` 是旧内核 P4 |
| 流速场 | 3 m/s 量程 + sqrt 量化（撞顶问题未解决） | 导出格式；重导需 5 m/s |

## 六、一次只动一处（单变量分解协议）

1. 固定：同工况、同种子、同人数、同时段、同机位、同时间层开关。
2. 只改一条开关，跑短时段（如 u_p80_s0 · 1020–1200 分 · 400 人，墙钟约 60–90 s）。
3. 报**这一处的增量**（Δ死/Δ困/Δ伤/Δ避险/Δ涉水），并注明基线同批跑。
4. 多条同时改的跑法（11-20 那次六处一起改）**禁止再用于归因**，只能用于出总数。

```bash
# 基线（全部默认）
node web/sim/sim-day.mjs 180 24 400 web/out/_sens/base.json 1020 u_p80_s0 20261117
# 单变量
SIM_KAPPA=2      node web/sim/sim-day.mjs 180 24 400 web/out/_sens/kappa2.json  ...
SIM_CROWD=off    node web/sim/sim-day.mjs 180 24 400 web/out/_sens/crowd_off.json ...
SIM_SLIP=off     node web/sim/sim-day.mjs 180 24 400 web/out/_sens/slip_off.json ...
SIM_SLIP_HI=1.4  node web/sim/sim-day.mjs 180 24 400 web/out/_sens/slip_hi.json  ...
SIM_SLIP_LO=0.35 node web/sim/sim-day.mjs 180 24 400 web/out/_sens/slip_lo.json  ...
SIM_RECV_RATIO=0.5 node web/sim/sim-day.mjs 180 24 400 web/out/_sens/recv05.json ...
```
