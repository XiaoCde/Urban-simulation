## 二、现在是决策模型吗？人遇到危险会自己决策吗？

**是，但要分人群讲清楚，不能一概而论。**

### 1）三层人群，两套机制

| 人群 | 数量 | 机制 | 遇到危险 |
|---|---|---|---|
| **具名角色**（马克、罗伯特、医生、工人、店员、骑手、女孩） | 7 | `decision.js` 的 `Brain`：有限视距感知 → `Belief` 5 m 网格信念表 → 候选效用打分 → 选最优；带 `PROFILES` 性格档案（风险厌恶、责任感、耐心、噪声） | 暴雨窗口真决策；其余 23h 每 25 分钟做一次日常权衡 |
| **社会路人**（固定名册、8 种职业、有家和岗位） | 24 | 同一套 `Brain` + `PersonState` + 生理量 + 真实房间锚点 | 暴雨窗口用 Brain 在「继续走 / 绕高处 / 进楼避雨」中打分，记录写回 `p.decisions`（不进展示面板） |
| **随机行人** | 默认 24（可调到 3000） | **规则型刺激-反应**，不是效用决策 | 脚下积水 ≥12 cm → 逃难（3.3 m/s，离开步行网直奔最近高地）；一开下雨且脚干 → 找 ≥1.0 m 高处避雨（1.7 m/s，雨不停不下来）；有「困死」累计统计 |
| 车辆 | 96 行驶 + 70 停放 | 跟车/入口排队/红灯/涉水减速；马克车是独立轨迹 | 水深 >0.35 m 熄火压井、>0.95 m 真开不动 |

### 2）Brain 怎么打分（`web/src/decision.js`）

```
感知 perceive(pos, t)：只在 sightM 半径内每 6 m 采一次水深，写进 Belief；半径外一个点都不读（不是上帝视角）
估计 estimateRoute(path)：沿路径往前看 lookAhead 米，未见过的地方用「附近最深水 × 衰减」当先验，输出 maxDepth / wetRatio / unknownRatio
效用 U = 1.15·survival + duty·dutyWeight − 0.30·effort − 0.34·timeCost
         − riskAversion·0.42·uncertainty − waitWeight·(1−patience) + noise
其中 survival = clamp(1 − (maxDepth / wadeLimit)·0.92, 0, 1)
```
候选由调用方给出「做什么、代价多远、离职责多近」，Brain 只算效用并排序，选第一名；全过程写进 `decisions`（含每个候选的分数与理由），HUD 与详情面板读同一份数据。

### 3）危险自决策的两个实例

- **暴雨 17:52–18:35（43 分钟）**：`mark-story.js` 在「上车前 / 车内遇淹 / 步行遇深水」三个点调 `brain.decide()`。默认档案在 18:02 遇到前方 0.4 m 积水超过 `carWade=0.35` → `carblocked` → 重新打分选**掉头绕 6th St**；谨慎档案会直接选步行、遇水再退回绕行。24 位社会路人同期在「继续走 / 绕高处 / 进楼避雨」中打分。
- **全天日常**：`day-think.js` 每 25 分钟让 31 人在「按计划 / 抄近道 / 先停一下」里权衡一次。24h 模拟实测 **7 人各 37 次 + 24 人 432 次，31/31 全覆盖**，不再是「只有暴雨那 43 分钟有脑子，其余时间照表摆位置」。
- HUD 标题行现在直接显示 `Brain N 次判断` 和最近一次判断，演示时不用翻日志。

### 4）边界（请如实看待）

- 不是 LLM、不是强化学习、不是全局最优规划；是**确定性效用打分 + 有限视距 + 性格噪声**，可复现、可解释。
- 海量随机行人是规则避险模型，没有个体记忆与长期目标；只有 7+24 人有 Brain。
- 险情决策只覆盖剧本预设的 43 分钟窗口；窗口外遇突发积水由规则层处理，Brain 不接管。
- 人车回写流场是「局部退水时间重参数化」，不守恒、不重新解浅水方程。

## 四·补、全城市民与年龄/经验分层（2026-11-10 新增）

之前街上只有 24 位「有脑子的社会路人」，且像一个模子刻出来的。这一轮扩成**全城 240 位市民**，
每人都有身份、职业、家、岗位、Brain、生理状态和作息，差异由「年龄 × 经验」驱动，不是换文案：

| 维度 | 儿童 (39 人) | 中年 (157 人) | 老人 (44 人) | 老手 (104) / 新手 (65) |
|---|---|---|---|---|
| 平均步速 | 1.00 m/s | 1.42 m/s | 0.87 m/s | 经验越高步子越稳 |
| 暴雨应激 | 0.971（最紧张） | 0.591 | 0.463（最稳） | 经验压住应激 |
| 感知半径 / 决策噪声 | — | — | — | 48.6 m / 0.047 vs 29.1 m / 0.131 |
| 典型决策 | 找大人 / 先站着看 | 沿熟路绕到高处 | 在屋檐下等雨小 | 老手 76 票绕行，新手 0 票 |

- **经验不是标签**：它直接写进 `Brain` 的 `sightM`（感知采样半径）、`noise`、`riskAversion`、
  `patience`、`wadeLimit`，并决定这个人**想得出哪些候选**。老手有「沿熟路绕到高处」
  且路径点大多已知（uncertainty 低）；新手只看得见「跟着人群 / 先站着看别人怎么做」，
  路线全是未知，风险厌恶把分拉低。等待型候选不再被「未知路况」罚分，老人「等雨小」才选得出来。
  暴雨 18:10 实测产生 **12 种不同选择**。
- **全城分布**：`ped.js` 把可走链按 420 m 网格聚成片区，选彼此相距 ≥420 m 的中心，
  实测覆盖 **39 个网格、x 跨度 4.7 km / z 跨度 3.1 km**；FAA/MegaKit 街区与官方
  「9 行人近景」白宫-拉斐特广场街区各加权，出生链收进机位 110 m，两个官方机位下都有人。
- **任何时刻街上都有人**：8 档作息按片区轮转（不是全城同一分钟起床），实测
  00/03/06/09/12/15/21/23 点街上 75–106 人，暴雨 18:00–18:20 全员 240 人在街上避险。
  决策按人错峰，单分钟最多 80 人做 Brain 感知，不会同帧卡顿。
- **场景简化但动作连贯**：家 / 岗位只是 42 个「容量制门牌」（每门上限 8 人，实测最大 8），
  不为几百人各建一间房。人到门口 5.5 m 阈值就直接进去（模型收起）；进屋前**沿步行网
  再走 6.5 m**，播 walk 且有真实位移，不会从街上瞬移到 9F，也不会「说在走动却原地跑」。
  岗位场景按职业地点分配（小学教师不再站到 FAA 6F 工位）。
- 顺手修掉一个隐藏很久的 bug：旧主循环按 `crowdState().count` 全局砍掉「前 N 个」行人，
  `setCount` 只写 `obj.visible` 不写 `p.visible`，距离裁剪下一帧不会恢复 ——
  **夜里和上午的行人被永久隐身**。现在街面人口只由社会层逐人决定，HUD 也改读真实统计。

**验收**：`_check_citizens.mjs` 19/19 PASS（速度/心理/感知/决策方向/容量/场景身份/
0 原地跑 / 0 可见瞬移 / 0 页面错误）；回归 `_check_round8` 12/12、`_check_actions` 0 FAIL、
`_check_carclip` PASS、`_audit_timeline` 190 点 0 错配、`_check_playwalk` 239 人 0 原地跑。
新截图 `out/ui/city_01_0020_night.jpg` → `city_08_1200_overhead.jpg`，其中
`city_07_1240_closeup.jpg` 是贴身跟拍，可看清人物落地与自然姿势。

**演示补充**：点右下「9 行人近景 / 0 行人俯视」看人群；拖时间轴看不同时段街上人数
（底部控制条会显示「街上 N 人 / 室内 M 人」）；拖到 18:10 看暴雨全员避险。
