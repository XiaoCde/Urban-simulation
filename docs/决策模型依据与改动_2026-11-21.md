# 决策模型：依据、数据来源与改动

本文说明三件事：模型里每个参数取自哪篇文献的哪张表、每个输入量来自哪份真实数据、依据这些文献改了什么。代码位置一并给出，便于逐条核对。

## 一、决策链总表

一个居民在某个时刻遇到积水，要做三件事：知道有危险、决定要不要采取保护行动、决定是撤还是留。三层各有文献支撑，另有一条时间维决定"什么时候动身"。

| 环节 | 依据文献 | 取用的参数 | 落地位置 |
| --- | --- | --- | --- |
| 认知层：情境知识 | Thieken et al. 2023, NHESS 23:973–990, Table S2（n=1,097） | 官方预警 0.571、预警信息 0.147、性别 0.493、既往洪水次数 0.680/0.901/2.010/2.001、意外事件 −0.648、洪水影响 −0.078 | `web/src/kernel/choice-model.js` |
| 行动层：保护行为 | Thieken et al. 2023, Table S3（n=1,003） | 情境知识 0.296、年龄 −0.012、既往洪水 0.212、意外 −0.248、水深编码 −0.28 | 同上 |
| 选择层：撤还是留 | Borowski & Stathopoulos 2023, NHR 24(1):04022045, Table 4 | 疏散 ASC 4.22、成本 −3.71、同伴乘车 −1.27、同伴留下 7.76、旅行时间 −0.02、等待时间 −0.03、步行距离 −1.08、年龄 0.21、同伴留下×moderate −9.27、×extreme −21.13 | 同上 |
| 时间层：动员 | Silva et al. 2025, NHESS 25:1501–1520, Table S2 与 Eq.(S2) | 8/24/72 小时动员率 88.8% / 95.7% / 98.6% | `web/src/kernel/warning.js` |
| 水深分档 | Thieken et al. 2023, Table S1 | 1 无水、3 ≤0.5 m、4 0.5–1 m、5 1–2 m、6 2–4 m、7 >4 m | `web/src/kernel/choice-model.js:105` |
| 碎屑因子 | FD2321 / WRL TR1, Table 3.1 | ≤0.25 m 取 0，0.25–0.75 m 取 1，>0.75 m 或流速 >2 m/s 取 1 | `web/src/kernel/hazard-input.js` |

### 公式逐项溯源

现用式子：

```
prior = 0.80 × (0.50 × 情境知识得分 + 保护行为得分)
V     = 0.25 × (U撤离 − U留下) + prior + 威胁档效用
p     = sigmoid(V) × 水深暴露 × (0.15 + 0.85 × 动员率)
是否行动 = 抽样 < p
```

逐项拆开，每块单独标出处与性质：

| 项 | 出处 | 性质 |
| --- | --- | --- |
| `sigmoid(·)` | 二元 logit 的标准形式，Borowski Table 4 就是二元 logit | 文献 |
| `U撤离 − U留下` | Borowski Table 4，系数与交互项齐全 | 文献 |
| 前面的 0.25 | 无 | 自设 |
| 情境知识得分、保护行为得分各自的系数 | Thieken Table S2 / Table S3 | 文献，但原文用于有序 logit 的潜变量，不是效用 |
| 知识→行动的 0.50 | 无 | 自设 |
| 得分→prior 的 0.80 | 无 | 自设 |
| 三项相加这件事本身 | 无 | 自设 |
| 威胁档 0 / 0.35 / 1.30 / 2.60 | 无 | 自设 |
| 水深档 (grade−1)/6 | 档位来自 Thieken Table S1，归一化无出处 | 半自设 |
| 基础暴露 0.15 | 无 | 自设 |
| `× 动员率` | Silva Eq.(S2) 给动员比例 | 文献，但"当乘子用"这一步自设 |

必须承认的三点：

1. **单项有出处不等于合起来有依据。** 加法本身不算捏造——logit 就是线性指数。问题在于把三篇在不同样本、不同因变量上估出来的系数放进**同一个**线性指数，等于假定它们的效用尺度可比。这个假定没有文献支持。
2. **三个权重（0.50 / 0.80 / 0.25）是拍的**，既不是拟合，也不是从论文换算，也没做过敏感性。
3. 最后再乘一次"暴露度"，等于对"是否采取行动"的概率二次打折，这一步同样没有出处。

### 有依据的替代结构

先把那三个"权重"的身份说清楚。Swait & Louviere (1993, *Journal of Marketing Research* 30(3):305–314) 指出：不同数据集估出来的 logit 系数其实是 λβ 的乘积，λ 是尺度参数，**合并两组系数之前必须估计或检验 λ 的比值**。也就是说 0.25 / 0.50 / 0.80 不是"可以定一个"的权重，而是必须估出来的量。拿不到两篇论文的原始数据就估不出来，所以正确的做法不是另定一个数，而是**不让它们出现在同一个式子里**。

去掉拼接之后，只剩一种结构，而且它是 Silva 自己的做法：

```
P(撤离)   = σ(U_Borowski)                # 系数：Borowski Table 4，原样
何时动身   = 1 − exp(−(t/b_m)^(2/a_m))    # 参数：Silva Eq.(S2)，a_m、b_m 原样
没动身的   = 垂直撤离（上楼、阁楼、屋顶）    # 判据：LifeSim CPD-97a Table 4-3
```

三件事各由一篇文献负责，**不相乘、不相加**。Silva 的 LifeSim 本来就是这个流程：先用预警扩散加动员曲线决定"谁动、什么时候动"（2021 年 Ahr 谷实测 34 % 离家），没动的人做垂直撤离，水深只决定"上不上得去、上去之后会不会淹"。动员曲线也不是 Silva 拟合的，是 Sorensen & Mileti (2015b, c) 给的，Silva 只是把 Eq.(S2) 与 a_m、b_m 搬过来。

处理后，原式里的自设数全部消失：0.50、0.80、0.25、威胁档四值、基础暴露 0.15 都不再出现。Thieken 的认知层与行动层退出主公式，改为**分层验证**——按情境知识分组，看撤离率的方向是否与 Table S2 / S3 一致。

代价如实说：撤离率会明显上升（Silva 实测 34 % 离家，我们 v2 最湿工况只有 6.2 %），死亡结构会跟着变，而且这套改法必须重跑八工况才能报数。

## 四、依据这些文献改了什么

### 决策逻辑（11-19，六处）

1. **从众参照对象**：从"同一户"改成"同一街区 120 米内的 3 个邻居"。依据是个案编码里避险行为的邻里传播特征。
2. **随机参数的个体差异**：成本、同伴乘车、同伴留下三个随机参数改成各自独立正态抽样、按人抽一次全天固定。旧实现共用一个偏差且每次判断重抽，个体差异被平均掉，全城收敛到均值 7.76。
3. **威胁与同伴的交互**：Borowski Table 4 的交互项 −9.27（moderate）、−21.13（extreme）意味着威胁升高时，同伴留下的正效用 7.76 会被抵成负数。这一点此前被忽略。
4. **雨强驱动重估**：情境签名里加入雨强档（无雨 / <5 / <15 / <30 / ≥30 mm/h），跨档立即重估，30 分钟窗口降为兜底。
5. **涉水影响行走速度**：修掉"深水里和干地上走得一样快"的错误，`web/src/ped.js:2376-2385` 的 `spd *= max(0.25, min(1, vd/v0))`。
6. **死因两维化**：从四类笼统说法改成"地点×动作"，与个案库可逐条对照。

### 积水与流速（11-20）

7. **建筑进水判据**：从"轮廓框内任意一点水深 >5 cm 即淹"改成"水淹过一楼地面才进水"。台基高度按 FEMA 默认值校正——初版截断 1.2 m 属无依据处理，且高估 3–4 倍，校正后同场雨淹楼数从 659 栋降到 130–200 栋。
8. **流速接入**：补 vel/dir 场，逐帧 md5 与水深帧比对（23/23、32/32 一致）。
9. **冲走判定**：按 FD2321 的 HR 累积风险率，锚点 0.004/s（HR 2.5 时约 50% 在 2.9 分钟内失稳）；室内与地下室不套用室外流速。

### 时间层（11-20）

10. **预警拆三个钟**：政府发布（雨前 30 分）、个人收到（对数正态，中位 60 分，35.5% 始终收不到）、动身后延迟（中位 8 分）。收不到的比例取自 Thieken 2022 表 4。
11. **动身门控**：`web/src/ped.js:2254`，只推迟"下雨就想跑"的那批，水已过涉水线的不受门控。

### 报数口径（11-20）

12. **补两个出口**：`web/src/incidents.js:620-666` 的 `expectedIndoorDeaths`（室内路径有个人固定阈值，期望值即概率）与 `outdoorMargin`（室外深水秒数对耐受的余量）。

## 六、范围与限制

- 水深和流速是**浅水方程算出来的**，不是实测值。缺地下管网与河道资料。
- 外部核对两次阴性：706 条 DC 311 里 15 条（2.1%）落在市府内涝范围，CSI 0.017。我们的栅格只覆盖 6.0 × 5.1 km 市中心，706 条里 492 条在域外。
- 死亡是单次抽样（1000 人、种子 20261117），0–3 人的差异不携带信息。
- 两个雨型族不可横向比较。
- 动员曲线出自化学品泄漏、火山、山洪研究，属跨灾种外推。
- 层高与人均楼面由 2–4 层建筑研究外推到 DC，属限制。
- 涉水步速只有单一来源（中科大泳池实验，同年两篇论文为同一批数据）。
- 撤离率对不上：Silva 2025 的 2021 Ahr 谷实测是 57 % 收到预警、17.5 % 收到含撤离指令的预警、34 % 离家；我们 v2 最湿工况避险率只有 6.2 %，低一个量级。在改成 §一 的结构之前，这个差距不能解释成"DC 人更不爱躲"。

## 七、待核的一处

成本系数 −3.71 的单位尚未核实。若按每美元，设计均值 11.60 美元 → −43，会压死 ASC 4.22，模型给出接近 0% 撤离率，与 Borowski 报告的选样比例不符；若按每 10 美元，−3.71 × 1.16 = −4.30，与 4.22 平衡。现行代码把四个属性归一化到 0–1 再乘，实际造成成本压 40 倍、时间压 60 倍、距离放大 2 倍，已登记为缺陷（`web/src/kernel/attributes.js` 的 `FEED_MODE`），待核原文 Table 3/4 后修正。
