# 逐栋首层标高：单变量 A/B（2026-11-20）

目的只有一个：`v1 → v2` 同时动了两处（相机解耦、逐栋首层高），
上一份 `docs/8工况v2结果_2026-11-20.md` 因此说不清死伤变化该归谁。
这一轮把首层高单独关掉、其余全同，量它的净效应。

## 一、怎么关的

不改内核语义，只加一个对照开关（可复现，默认行为不变）：

| 位置 | 改动 |
| --- | --- |
| `web/src/terrain.js` `loadFoundationTable()` | 认 `?found=off`：打 `console.warn('[foundation] found=off · 本次按全城 0.457 m 跑（A/B 对照，不混报）')`，`window.__foundation={count:0,scenario:'off'}`，直接 `return 0`（等于没注册逐栋表，`foundationMFor()` 全走默认） |
| `web/sim/sim-day.mjs` | 加 `SIM_FOUND` 环境变量，透传成 URL 参数（`if (FOUND) u.searchParams.set('found', FOUND)`）；`agg.foundation` 照常记录 |

生效证据（`out/_ab_foundOff/*.partial.json`）：

```
agg.foundation = {ready:true, scenario:"off", buildings:0, persons:1000,
                  hist:{"none":1,"0.46":999}}
```

对照 ON 的那一侧是 `scenario:"B_老城排屋", buildings:21147, hist:{0.30:442,0.46:163,0.70:30,1.07:146,1.22:218,none:1}`。
即 OFF = 999 人回到 0.457 m（唯一 1 人 `none` 是具名马克，他不在人群抽样里）。

## 二、跑法

```
cd web
SIM_FOUND=off node sim/sim-sweep.mjs "u_p24_s0,u_p32_s0,u_p80_s0,u_p120_s0" \
  2 1000 1440 out/_ab_foundOff
```

选这四档的原因：两族各取两档，且在 v2 里死亡最多的四档。
ON 的一侧直接复用 `out/sweep_v2/` 的同工况结果（同 seed 20261117、同 1000 人、同 1440 分）。

## 四、怎么读这组数（这一节比数字重要）

1. **首层高对伤亡的净效应约为 0**，两侧差异全部在 1 人以内，落在换种子的正常波动里
   （`docs/报数口径_2026-11-20.md`：0–3 人的差在 n=1000 下不可区分）。
2. **地下室死者数完全不动**（3 vs 3、5 vs 5），这不是巧合，是模型结构决定的：
   `web/src/incidents.js:446-448` 的地下室当地水深是
   `dExp = depth + BASEMENT.depthM`（`kernel/floors.js` 的埋深 2.2 m），
   **完全不经过 `foundationM`**。首层抬 0.6 m 影响的是室内楼层判据，不是地下室。
   所以「抬首层高能少死地下室人」在本模型里不成立，别这么写。
3. 两侧 ±1 的死差来自**轨迹分叉**，不是抽签：避险人数先变了（92 vs 96、38 vs 41），
   路线跟着变，于是谁踩进深水变了。室外判死是确定性的（`incidents.js:508`），
   同一个人走同一条路必死或必不死，所以这属于「输入扰动」，不是「概率抽样」。
4. 首层高真正改变的是**淹楼/楼层进水**这类量（`docs/首层标高校正_2026-11-18.md`
   算过淹楼 163 / 540 / 3358 的差别），而当前 1000 人里室内路径的人少、能到致死深度的更少。
   **结论：这一改动在结构上是必要的（原来全城一个常数是硬错），但它在伤亡列上测不出效果；
   不要拿它当解释 v1→v2 数字变化的理由。**

## 五、限制

- 单种子（20261117）、单人数（1000）。±1 的差不能作为「方向」证据。
- 只测了四个工况。全天族 8/16 两档没测（那两档死亡更少，差异会更不可测）。
- 工作场所仍不判楼层（只接了「在家」那条），所以白天在办公室被淹的风险仍缺。
- 796 栋（3.6%）没有 FEMA 值，回退 0.457 m；`none:1` 是具名马克。
- 三组假说（A/B/C）之间没做敏感性，只跑了默认 B。
