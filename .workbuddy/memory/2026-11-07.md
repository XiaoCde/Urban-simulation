## 2026-11-07 中午 · 24h 人物「不动 / 半夜在街上 / 原地跑」返工

用户反馈：人物连动都不动；马克大半夜在外面不在家；买早餐在原地跑；其他人一样。

### 三个真 bug

- `mark.js` / `people.js` 的 applyDay 全改读 day-motion；crisis 1072–1115 仍交 story+Brain。
- `main.js`：室内有人时把楼外壳 ghost 到 opacity 0.26（材质缓存两份、状态变化才换引用），每栋放一盏暖色 PointLight；相机进精细楼时整片收雨（每帧算一次，occlude 只读缓存）。

## 2026-11-07 晚上 · 第七轮：场景对位返工 + 代码 bug 清扫

用户反馈：场景还是差强人意、很离谱，再修一遍，并检查代码 bug，最后把当前 UI 截图给他看。

### 真正离谱的原因：楼面高度全错（最核心）
`life-scenes.js` 一律用 `floorH=3.6`、`baseY=地面` 抬高室内场景，但真实建筑是：
公寓 565 Penn `3.55 / baseY 11.28`、办公楼 FAA `5.0 / 7.19`、诊所 `4.0`、学校 `5.0`、咖啡馆 `3.3`。
后果：办公楼 6F 的工位比真实楼面**低 7 米**（摆进 1–2F 的墙里）、公寓 9F **高 2.8 米**（家具浮空）、
公寓 1F 大堂**低于楼面 3.2 米**。人物的房间锚点也继承了这个错误 → 人站在楼板里。
