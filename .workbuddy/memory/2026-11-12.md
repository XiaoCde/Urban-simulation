# 2026-11-12 · 3000 人实时决策城：人口精细分层 / 全城分布 / 经历记忆 / 伞状态化

## 用户要求
再复查决策与全城是否正确；各类人从小到老、各类职业精细加入；人数加到 3000 且人人自主判断；
必须全城分布不故意扎堆；把状态值加进去，「今天干了什么、经历了什么」要影响后续走势；
伞除马克外不建模，只在后台状态里带；保证人物动作跟着决策走。

## 基线探针查出的真问题（`web/_probe_base.mjs`，只读）
- 年龄只有 3 档：无 0-5 / 13-17 / 18-24，56-64 岁全城仅 1 人；75+ 老人仍会被派去当钢筋工/外卖骑手。
- 职业仅 8 类；`cohort.STATUS_BY_ROLE` 漏掉 6 个具名角色，全部悄悄落到默认「服务业」。
- 伞两处各 rand() 一次 → 1000 人中 469 人 `p.hasUmbrella` 与 `phys.hasUmbrella` 自相矛盾。
- 岗位只有 42 个固定门牌：`work_school_0` 挂 48 人；18:00 一个 120m 网格挤 240 人（224 个 shelter），根因是 `findRefuge` 全城选同一个「最近高地」。
- `CROWD.tick` 写死 `speed: 0` → 体力/饥饿/淋湿几乎不随真实运动变化，状态值是摆设。
- 快判断的 hurry/slow 只改 route.speed 与文案，动画不跟；route 模式被 `clipOf` 判成 idle（滑步）。

## 架构改动（单一真值优先）
- 新建 `src/roles.js`：32 种职业 → 地点/场景/社会地位/允许年龄段/室外/夜班/备伞率，年龄与职业硬约束（幼儿不工作、学生只上学、65+ 基本退休、75+ 不做重体力）。`crowd-life` 与 `cohort` 共用，具名角色有别名映射。
- `src/citizen.js`：3 档 → 9 档 `AGE_BANDS`（学龄前/儿童/青少年/青年/青壮/中年/中老/老人/高龄），每档独立步速/体力/应激/耐心/涉水线/视野/经验基线；`ageGroup` 三大类只保留作兼容汇总。
- 新建 `src/experience.js`：每子步量出的真实位移/最深水/涉水时长/檐下时长 + 每次判断与目标事件，累积成 `expDepth / detoursToday / abandonToday / doneToday / wetness / fatigue / homeBias / confidence / umbrella`，直接进 `cohort.judge()` 各项分数与 `speedFactor()`（改的是真实步速）。
- `src/goal.js`：按身份分 4 套目标模板（work/student/retired/night），节点自带 `destKey` 明确门牌；节点交界 20 分钟内可补激活（修拖轴快照「全城无目标站街上」）。
- `src/person-state.js`：雨强驱动淋湿、撑开的伞挡 85% 且淋湿上限 0.55；`ped.js` 改为传真实步速/水深/室内外/睡眠。
- 伞：只算一次随机；`shouldShelter()` 让带伞的人继续赶路、没伞的暴雨才躲；不建任何普通行人伞模型。
- 避雨扎堆：`findRefuge` 加容量负载 + 按人序分散偏置 + 避雨就近 220m；`scatterRefuge()` 把同一楼边的人散到不同墙边；`syncRefugeLoad()` 每 30 帧按真实状态重算。
- 全城分布：`bindResidents` 住宅容量按建筑数自适应、岗位/餐馆/室外场景改为「离家 180~600m 的真实建筑门牌」（空间哈希 O(n)），普通市民不再被摆进剧情楼房间锚点。
- 动作跟决策：`clipOf` 认 route 模式与 hold；`applyLiveAction` 里 hurry 直接播 run、slow 播慢走、wait 站定、放弃可见停步；`clipTimeScale` 步频随真实步速；帧末零位移兜底扩展到所有人、阈值 2m。
- 冷却收敛：detour 120s（硬排除）、abandon 600s、wait 30s；`planRetryT` 与 `nextThink` 分离，规划排队不再给人降频；檐下避雨用受限候选池仍每 0.5~1s 判断。

## 实测（3000 人，`_probe_final.mjs` / `_probe_base.mjs`）
- 默认 00:00 打开；0 点 2999 人在各自住所、0 室外、0 悬空；全天 5 个采样点离地 >1.2m 为 0。
- 9 档年龄全覆盖、33 种职业、28 个判断内核；伞字段不一致 0（1798/3000 备伞）。
- 住宅 1576 个门牌（单门最多 3 人）、岗位 2223 个门牌（最多 6 人）；18:00 室外 2306 人分布在 450 个 120m 网格，最密 41 人（原 242）；7:00 最密 33 人。
- 连续播放：白天室外人员 **1221/1221 全部自主判断**；×1 对 ×12 分钟 12.00×、仿真秒 12.00×、每仿真秒判断率 0.99~1.01×（倍率同层）。
- 动作：hurry 时 3730 帧播 run（原 0）、wait 全部 idle、零位移仍播走跑 3/45 万采样（原 1271）。
- 经历影响走势：蹚过 >22cm 深水者人均绕行 39.4 vs 18.3；淋湿者等待 82.9 vs 13.2；有伞淋湿 7.6% vs 没伞 60.5%，檐下 3s vs 348s。人均绕行降到 1.72 次/16 分钟、放弃 0.57 次。
- 回归全绿：citizens 19/19、routes 17/17、playwalk 无原地跑、actions 0 FAIL、carclip 车不穿楼、timeline 190 点 0 错配、页面 0 脚本错误。

## 遗留
- 正式 24h 连续验收 `web/_sim_day.mjs` 仍未跑（按用户要求后期找空闲再跑）；本轮只做了最长 200 分钟仿真片段。
- 无头 SwiftShader 软件渲染下 3000 人加载约 19.5s；真机 GPU 会快，但 ×48 长时间连续运行的实机 CPU 未测。
- 旧 Brain 的候选/文案仍作为「记录层」存在（`decide()`），实时判断与位移已完全由 live-agent 驱动；未做彻底删除以免破坏旧验收。
